시작하기처음 쓰는 분은 여기부터

이 시스템은 무엇을 하는가

IPMES는 금형 한 벌이 수주에서 납품까지 가는 동안 생기는 모든 기록을 제번(작업번호) 하나로 묶어 관리하는 시스템입니다. 기록을 모으는 것이 목적이 아니라, 그 기록에서 제번별 실제 원가와 품질 증빙이 자동으로 나오게 하는 것이 목적입니다.

① 계획을 세운다

수주등록 → 제작계획등록 → PartList 등록. 무엇을 언제까지 얼마에 만들지 정합니다.

② 실제로 만든다

발주 → 입고 → 입고확정, 작업지시, 설계·조립 실적등록, 검사실적등록.

③ 결과가 자동으로 나온다

제조원가·품질 KPI·추적성·심사 증빙이 입력한 기록에서 자동 집계됩니다.

그래서 ②를 빠뜨리면 ③이 조용히 틀어집니다. 이 매뉴얼이 「입고확정」과 「실적등록」을 반복해서 강조하는 이유입니다.

💡 화면이 많아 보이지만 실제로 매일 쓰는 화면은 본인 업무의 3~5개뿐입니다. 「업무 흐름 › 역할별 담당 화면」에서 본인 것만 확인하세요.
💡 어느 화면에서든 하단 메시지줄에 결과가 나옵니다. 저장이 됐는지 안 됐는지는 항상 거기서 확인합니다.

로그인과 권한

시스템 접속과 메뉴 표시 규칙입니다.

  1. 주소로 접속하면 로그인 창이 뜹니다. 사용자정보에 등록된 이메일 + 비밀번호로 로그인합니다.
  2. 로그인하면 권한이 있는 메뉴만 상단과 좌측에 표시됩니다. 필요한 메뉴가 안 보이면 관리자에게 권한을 요청하세요.
  3. 비밀번호를 잊으면 관리자가 기준정보 > 사용자정보에서 [비밀번호 재설정]으로 임시 비밀번호를 발급합니다.
💡 세션은 자동 연장되므로 업무 중 재로그인은 필요 없습니다.

화면 이동 · 탭 사용

메뉴는 3단 구조입니다: 상단 모듈 → 아이콘(2차) → 좌측 트리(화면).

  1. 상단에서 모듈(영업관리, 설계관리…)을 클릭합니다.
  2. 그 아래 아이콘 줄에서 업무 묶음(수주, 제작계획…)을 클릭합니다.
  3. 좌측 트리에서 화면 이름을 클릭하면 탭으로 열립니다. 여러 화면을 탭으로 띄워놓고 오가며 작업할 수 있습니다.
  4. 탭의 ×로 닫고, 화면 하단의 [⊠ 닫기] 버튼도 같은 동작입니다.
  5. 좌측 트리와 본문 사이 경계선을 드래그하면 트리 폭 조절, 더블클릭하면 기본폭으로 돌아갑니다.
💡 화면 확대(Ctrl+마우스휠) 시 상단 메뉴가 아랫줄로 접히며 전부 유지됩니다.

입력 화면 공통 규칙

등록/입력이 붙은 화면은 모두 같은 패턴입니다.

  1. 코드 입력칸 옆의 […] 돋보기 버튼을 누르면 조회 팝업이 뜹니다. 검색어 입력 → 행 더블클릭(또는 선택)하면 코드와 이름이 자동 입력됩니다.
  2. 목록의 행을 클릭하면 폼에 불러와져 수정 상태가 되고, [＋ 신규]를 누르면 빈 입력 상태로 돌아갑니다.
  3. [▣ 저장]은 신규면 등록, 기존 행을 불러온 상태면 수정으로 동작합니다.
  4. 삭제는 행을 선택(또는 체크)하고 [✖ 삭제] → 확인창에서 확인.
  5. 기준정보 화면 하단의 [엑셀 붙여넣기]: 엑셀에서 범위를 복사(Ctrl+C) → 버튼 클릭 → 붙여넣기(Ctrl+V) → 열 짝을 확인하고 등록하면 대량 입력이 됩니다.
  6. 저장 결과는 항상 화면 하단 메시지줄에 표시됩니다. '실패'가 뜨면 메시지의 원인(필수값 누락, 미등록 제번 등)을 확인하세요.
⚠ DB 미연결 상태에서는 저장·삭제가 되지 않습니다. 하단에 '미연결' 메시지가 보이면 네트워크를 확인하세요.

업무 흐름무엇이 무엇으로 이어지는가

업무 전체 순서 한눈에 보기

MES의 모든 메뉴는 아래 순서로 맞물려 돌아갑니다. 신규 수주 1건이 완제품 출하까지 가는 표준 경로입니다.

  1. 기준정보 등록 — 업체관리(고객사·협력업체), 부품·자재·공정, 단가관리를 먼저 등록합니다. 모든 화면의 돋보기(…) 조회는 여기 등록된 자료만 보여줍니다.
  2. 수주등록 (영업관리) — 제번을 발급하고 수주정보를 저장합니다. 저장하는 순간 모든 후속 화면의 '제번리스트'에 나타납니다.
  3. 제작계획등록 — 수주 제번을 불러와 설계·가공·조립 일정과 목표원가를 세웁니다.
  4. PartList 등록 (설계관리) — 공정별 원재료/구매품 소요를 등록합니다. 구매관리의 발주 화면은 PartList를 그대로 자재표로 씁니다.
  5. 발주 (구매관리) — 원재료·구매품·외주가공을 발주하고 발주서를 인쇄해 협력업체에 보냅니다.
  6. 입고 → 입고확정 — 물건이 도착하면 '입고' 처리, 검수가 끝나면 '입고확정'. 입고확정된 금액만 제조원가에 집계됩니다.
  7. 작업지시 + 공정이력카드 — 사내 가공 건은 작업지시를 내리고 공정이력카드를 발행해 제품과 함께 이동시킵니다.
  8. 설계·조립 실적등록 — 작업자가 작업시간(분)을 매일 등록합니다. 사내 인건비 원가의 근거가 됩니다.
  9. 검사실적등록 — 검사 결과를 기록하고 합격 시 입고확정 처리합니다.
  10. 제조원가조회(실시간) (원가관리) — 제번별로 원재료·구매·가공·조립·설계비가 자동 집계된 원가를 확인합니다.
💡 처음 도입 시에는 1→2→3 순서대로 기준정보부터 채우는 것이 가장 빠릅니다.
💡 어느 화면에서든 막히면 이 메뉴얼의 해당 화면 항목을 열어 [화면 열기] 버튼으로 바로 이동하세요.

매일 할 일 (5분)

아침에 딱 두 화면만 열면 됩니다. 둘 다 SQ › 알림판에 있습니다.

  1. 기한관리 알림판을 엽니다. 상단 기한초과 카드 숫자가 0이 아니면 그 건부터 처리합니다.
  2. 입력누락 점검판을 엽니다. 경과일 7일 이상으로 걸러 오래 방치된 건만 봅니다.

💡 두 화면 모두 [▤ EXCEL]이 있습니다. 아침 회의 자료가 필요하면 그대로 내려받아 쓰세요.

매주 할 일 (30분)

주 1회, 원가와 납기가 새는 곳을 막는 점검입니다.

  1. 입력누락 점검판 → 원가 누락 카드를 눌러 「입고 미확정」 건을 전부 확정 처리합니다.
  2. 노무비 누락 카드 → 설계·조립 실적이 안 들어온 공정을 담당자에게 독촉합니다.
  3. 납기 지연 카드 → 미입고 발주를 협력업체에 독촉합니다.
  4. 기한관리 알림판에서 임박기준을 7일로 낮춰 이번 주에 만료될 계측기·자격·문서를 확인합니다.
  5. 가공구매 진척현황에서 제번별 진척을 훑고 지연 품목을 챙깁니다.
💡 「원재료·구매품 미발주」 항목은 PartList에 등록만 하고 발주를 안 낸 자재입니다. 납기 사고의 흔한 원인입니다.

월 마감 절차

원가를 확정하기 전에 반드시 이 순서대로 확인합니다. 순서를 지키지 않으면 마감 후에 숫자가 바뀝니다.

  1. 입력누락 점검판을 열어 경과일 0으로 두고 전체를 봅니다.
  2. 「입고 미확정」을 0건으로 만듭니다. 미확정 금액은 원가에 잡히지 않습니다.
  3. 「설계·조립 실적 미입력」을 정리합니다. 사내 노무비의 근거입니다.
  4. 「Try-Out 완료일 미입력」·「납품 완료일 미입력」을 채웁니다. KPI01·02가 이 값으로 집계됩니다.
  5. 경비등록에서 이번 달 경비가 빠짐없이 제번에 붙었는지 확인합니다.
  6. 제조원가조회(실시간)에서 제번별 원가·이익률을 확인하고 [▤ EXCEL]로 보고서를 만듭니다.
  7. 품질목표 달성현황에서 이번 달 KPI를 확인합니다. 「실적없음」이 있으면 원천 입력이 빠진 것입니다.
⚠ 마감 후에 입고확정이나 실적을 추가하면 이미 보고한 원가가 바뀝니다. 반드시 마감 전에 점검판을 비우세요.

고객 심사 준비

심사 통보를 받으면 이 순서로 준비합니다. 대부분의 지적은 기한 관리와 기록 누락에서 나옵니다.

  1. 기한관리 알림판에서 기한초과와 기한 미등록을 전부 0으로 만듭니다. 특히 계측기 교정·사원 자격이 1순위입니다.
  2. 계측기 교정현황 — 교정기한이 지난 계측기는 현장에서 즉시 회수합니다. 그 계측기로 잰 검사 결과는 무효입니다.
  3. 자격 유효현황 — 검사원 자격 만료자가 검사 실적을 올렸는지 확인합니다.
  4. 문서 유효현황·도면개정현황 — 「구본/구도면 미회수」 알림을 정리합니다. 현장에 구도면이 돌아다니는 것은 중대 지적입니다.
  5. 관리계획서 현황·기준공정 관리계획 커버리지 — 「측정기 미지정」과 「관리계획 없음」 공정을 보완합니다.
  6. 지적사항 조치현황·부적합현황 — 지난 심사 지적과 부적합의 시정조치가 종결됐는지 확인합니다.
  7. 협력업체 인증현황·등급현황 — 인증 만료 업체에 발주가 계속 나가고 있지 않은지 확인합니다.
  8. 심사 당일 요구 자료는 추적성조회(제번↔LOT↔밀시트↔성적서)와 각 현황화면의 [▤ EXCEL]로 즉시 뽑습니다.
💡 심사원이 「이 부품 소재 어디서 왔냐」고 물으면 추적성조회 한 화면으로 답할 수 있습니다.

수주등록

고객 수주를 접수해 제번(작업번호)을 발급하는 출발점 화면입니다. 여기서 저장해야 나머지 모든 화면에 제번이 나타납니다.

  1. 제번을 입력합니다. (필수. 회사 채번규칙에 따라 직접 입력)
  2. 수주일, Try-Out 예정일, 납기예정일을 달력에서 선택합니다.
  3. 수주상태(진행/보류/완료/취소), 수주유형(신작/개조/수리), 국내/해외를 선택합니다.
  4. 아이템·담당자·고객사·금형타입·양산처·기계사양은 [… ] 돋보기로 조회해 선택합니다. 목록에 없으면 기준정보에 먼저 등록하세요.
  5. 도번, 품명, 품번, 공정, 견적가/수주가/판매가, 사용재료, ECO, 비고를 입력합니다.
  6. 첨부파일: 제번 입력 후 [파일첨부] → 파일 선택(여러 개 가능). 업로드 후 [저장]을 눌러야 확정됩니다. 선택 후 [미리보기]/[다운로드]/[파일삭제]도 가능합니다.
  7. [▤ 저장] — 제번·수주·수주현황에 동시 반영됩니다.
  8. 다음 건 입력은 [✕ 신규]로 화면을 비운 뒤 진행합니다.
  9. 관리제번 + 공정 = 제번: 관리제번(예 26IPA001)과 공정(A~Z)을 넣으면 제번(26IPA001A)이 자동으로 만들어집니다. 공정이 하나뿐인 금형은 공정을 비워 둡니다. 제번 칸에 직접 입력해도 관리제번·공정이 자동으로 나뉩니다. 수주현황의 「관리제번별 묶어보기」로 한 금형의 공정들을 한 묶음으로 볼 수 있습니다.
  10. [⚙ 공정 자동생성]: 관리제번과 공정수를 넣으면 A·B·C… 공정별 수주가 한 번에 만들어집니다. 총 견적가·수주가를 균등 분할 / 비율 입력 / 금액 직접 입력으로 나누고, 공정마다 카테고리와 설비사양(프레스 톤수 등)을 따로 넣습니다. (회의록 1-2·1-3·1-4)
💡 기존 수주를 수정하려면 제번을 입력하고 다른 칸을 클릭하면 첨부가 자동 로드됩니다. 값 수정 후 저장하면 갱신됩니다.
⚠ 수주상태를 '취소'로 바꿀 때 이미 입고·확정된 발주가 있으면 취소되지 않습니다. 입고취소 후 진행하세요.

수주현황

등록된 전체 수주를 조회·관리합니다.

  1. 상단 구분(전체/진행/완료)과 수주유형 라디오를 선택합니다.
  2. 품번·도번·제번·품명·고객사·양산처 칸에 검색어를 넣고 [⌕ 검색].
  3. 행을 클릭하면 상세 팝업이 떠 수주 전체 항목과 첨부파일 링크를 보여줍니다.
  4. 잘못 등록된 수주는 행 선택 → [✕ 삭제]. (제번 자체는 유지되고 수주정보만 삭제)
  5. 열 제목을 클릭하면 정렬됩니다 (▲ 오름차순 → ▼ 내림차순 → 해제). 빈 값은 항상 맨 뒤.
  6. [▤ EXCEL]로 현재 조회 결과를 내려받습니다.
💡 하단 합계줄에 조회 건의 견적가·수주가·판매가 합계가 자동 표시됩니다.

제작계획등록

영업에서 쓰던 제번관리 엑셀과 같은 모양입니다 — 기본정보 · 금형제작 EVENT(요구/목표/가능 일정) · 제품 형상 · 진척현황 · 특기사항 · 금액.

  1. 제작제번을 입력하거나 고르면 수주정보(품번·도번·품명·고객사·수주가)가 자동으로 채워집니다. 기존 계획이 있으면 그 계획이 불려옵니다.
  2. 기본정보에 제작구분(신규제작·수정·추가), 조수, 재질·두께(예 GI 2.0T), 사이즈(예 W150·P46), 고객담당, 설계처·제작처·양산처를 적습니다. 양산처가 아직이면 비워 둡니다.
  3. 금형제작 EVENT 표는 접수·설계·가공·조립·초품·완료 6단계 × 3줄입니다. 요구일정은 고객이 요구한 날, 목표일정은 우리 계획(현황·진척 화면이 쓰는 기준), 가능일정은 지금 예상입니다. 가능일정이 목표보다 늦으면 칸이 노랗게, 빠르면 연두로 칠해집니다 — 엑셀에서 손으로 칠하던 표시입니다.
  4. 날짜 칸 위에서 마우스 휠을 굴리면 하루씩 바뀌고, 같은 줄의 오른쪽 일정(이후 공정)도 같은 만큼 함께 밀립니다. Shift+휠은 7일씩, Alt+휠은 그 칸만 바꿉니다. 새 제번을 열면 EVENT 표의 모든 날짜 칸이 오늘로 미리 채워지므로 휠로 밀어 가며 잡으면 됩니다. 기존 계획에서 빈 칸을 채우려면 요구일정 줄 오른쪽의 [오늘로]를 누르세요. 날짜 칸 오른쪽에는 요일이 (수)처럼 붙어 나오며 토요일은 파랑, 일요일은 빨강입니다. 제작계획현황 목록의 날짜도 9/23(수) 식으로 요일이 붙습니다. 현황 위쪽 검색칸은 제번·품번 기준이며, 품번 칸에서 고르면 그 제번으로 바로 조회됩니다. 목표일정의 접수는 제작계획에 입력한 날짜를 쓰며, 비어 있으면 수주일로 채워집니다.
  5. 같은 표 아래 줄에 설계·가공·조립의 시작일과 담당자, 가공의 사내/외주와 외주업체를 넣습니다. 일수는 자동 계산됩니다.
  6. 제품 형상 칸을 클릭해 그림(PNG·JPG)을 올립니다. 엑셀의 3D 그림 칸과 같습니다.
  7. 진척현황은 날짜와 내용을 넣고 [＋ 추가] — 엑셀의 ● 메모입니다. 날짜순으로 정렬되고 ✕ 로 지웁니다.
  8. 구성비 금액을 입력하면 목표가·이익률이 자동 계산됩니다. [▤ 저장]을 눌러야 전부 DB에 들어갑니다.
  9. 설계외주·조립외주 여부와 업체는 영업관리 › 설계외주 › 외주설계발주등록, 조립외주 › SET외주제작등록에서 발주하면 자동으로 바뀝니다. 가공 외주만 여기서 지정합니다.
💡 수주가 대비 목표가 이익률을 보며 금액을 조정하세요.

제작계획현황

세워둔 제작계획을 제번관리 엑셀 시트처럼 한눈에 봅니다 — 제번마다 요구/목표/가능 3줄, 제품 그림, 진척현황, 특기사항.

  1. 제번·품명(품번·품명 포함) 칸에 입력하는 즉시 목록이 걸러집니다. 지연만을 켜면 가능일정이 목표보다 늦은 제번만, 완료 숨김을 켜면 완료 목표일이 지난 제번을 감춥니다.
  2. 가능일정이 목표보다 늦은 칸은 노랑, 앞당긴 칸은 연두입니다. 제번 아래 「지연 +N일」 표시는 여섯 단계 중 가장 많이 늦은 일수입니다.
  3. 진척현황은 최근 3건만 보이고, 전체는 더블클릭 상세에서 봅니다. 제품 그림을 클릭하면 크게 열립니다.
  4. 행 선택 → [⌕ 상세보기](또는 더블클릭) → 계획 상세 팝업.
  5. 팝업의 [▤ 수정]을 누르면 제작계획등록 화면이 해당 제번으로 열립니다. 값 수정 후 저장.
  6. [✕ 삭제]는 계획만 지우고 수주정보는 남깁니다.
  7. [▤ EXCEL]로 목록을 내려받습니다.

원재료 발주

PartList의 원재료를 협력업체에 발주하고 발주서를 인쇄합니다.

  1. 좌측 제번리스트에서 제번을 클릭 — PartList(원재료)가 자재표로 뜹니다.
  2. 우측 협력업체리스트에서 발주할 업체를 검색·선택합니다. (업체가 없으면 기준정보 > 업체관리에서 '원재료' 체크와 함께 등록)
  3. 자재표에서 발주할 품번을 체크하고 입고요구일을 지정한 뒤 [⬇]로 아래 구매요청 리스트에 내립니다. 단가는 단가관리 등록분이 자동 적용됩니다.
  4. 수량·발주치수를 확인·수정합니다. 빼려면 체크 → [⬆].
  5. [▣ 저장] — 발주로 확정되어 발주현황·입고 화면에 나타납니다.
  6. [⎙ PRINT] — 체크한 행으로 발주서 미리보기가 뜨고, [⎙ 인쇄]를 누르면 발주서 영역만 출력됩니다.
  7. 여러 품번 한 번에 — 자재표에서 품번을 체크해 두고 그중 한 줄을 우클릭하면 열리는 창(발주·입고·입고확정)이 체크한 품번 전부에 함께 적용됩니다. 발주창에는 함께 발주할 품번 표가 붙고, 수량·중량·단가·금액(견적가)을 품번별로 각각 고칠 수 있습니다(처음엔 잔량·설계치수·업체별 단가 이력으로 자동 채움, 손으로 고친 값은 노랑). 확정가는 입고확정 때 네고율로 잡힙니다. 입고는 각 발주 잔량·발주단가로 같은 입고일에, 입고확정은 이 창의 확정일·네고율을 각 매입가에 적용합니다. 창 안의 초록 안내줄과 버튼의 (+N)으로 몇 개가 함께 처리되는지 보입니다. 발주완료 품번도 체크할 수 있어 입고·확정을 묶어 처리할 수 있습니다. 한 품번을 여러 업체에 나눠 발주한 경우(발주 내역 N건 창)에도 줄마다 체크가 있어 [▣ 입고 처리 (체크)]·[✖ 발주취소 (체크)]로 체크한 발주건을 한 번에 처리합니다.
  8. ✉ 발주서 메일 — 발주를 등록하면 바로 발주서 메일 창이 뜹니다. 받는 사람은 기준정보 › 협력업체관리의 이메일이 자동으로 들어가고, 발주 내역표와 PartList에 등록한 부품 그림(A4)이 함께 갑니다. [✉ 보내기]는 구글 앱스 스크립트 웹앱을 통해 회사 구글 계정으로 바로 발송(발주서 PDF + 부품 그림 첨부, 기록은 mail_log), 함수가 아직 없으면 [📨 메일 앱]으로 메일 프로그램을 열고 [🖨 발주서(A4)] 창을 PDF로 저장해 첨부하면 됩니다. 발주 뒤에도 그 공정(품번) 칸을 우클릭해 열리는 입고·확정·완료 창의 [🧾 발주서]로 그 부품의 발주서(같은 업체·발주일 발주건만)를 언제든 다시 열 수 있습니다.
💡 '단가 미등록 n건' 메시지가 뜨면 자재단가변동등록에서 단가를 먼저 등록하세요.

사내가공 실적등록

※ 이 메뉴는 사용하지 않습니다(비활성화). 사내 가공시간은 원가관리 › 금형원가(내역) 화면에서, 또는 외주가공 발주의 사내 칸을 우클릭해서 넣습니다. 아래 설명은 참고용입니다.
사내에서 가공한 부품별 가공시간을 기록하면 가공비(시간 ÷ 60 × 단가)가 자동 계산되어 제조원가에 반영됩니다. (회의록 3-2)

  1. 제번을 고르면 가공계획(부품별 공정)의 부품 목록이 나옵니다. 공정 표시에서 진한 칸이 사내가공입니다.
  2. 부품을 클릭하고 공정·설비·작업자·가공시간(분)을 넣은 뒤 [실적 등록]. 단가는 기준정보 › 단가관리 › 작업단가의 MCH(가공 공통) 또는 설비코드 단가를 자동으로 가져옵니다.
  3. [📐 도면]은 SQ › 도면등록에 등록된 그 품번의 도면을 엽니다. [⎙ 작업표지 출력]은 부품 정보와 가공공정 순서를 A4로 출력해 도면에 첨부합니다. (회의록 4-2·4-3)
  4. 등록한 가공비는 제조원가조회의 원가 내역에 사내가공비로 집계됩니다.

사내외가공 발주

부품별 가공공정을 한 표로 보고, 칸을 우클릭해 발주 → 출고 → 입고 → 입고확정까지 그 자리에서 처리합니다. 사내가공 공정은 여기서 가공시간을 넣습니다.

  1. 제번을 고르면 부품이 줄로, 가공공정이 칸으로 펼쳐집니다. 초록색 ▶ 다음 칸이 지금 발주할 공정입니다.
  2. 칸을 우클릭하면 상태에 맞는 창이 열립니다 — 미발주면 발주창, 출고면 입고창, 입고면 확정창.
  3. 연속한 여러 공정을 한 업체에 맡기려면 칸을 눌러 범위를 잡고 마지막 칸을 우클릭하면 묶음 발주가 됩니다.
  4. 갈색 사선 칸은 사내가공이라 발주가 아니라 완료 등록을 합니다. 우클릭하면 완료일·작업자·설비·가공시간(분)을 넣는 창이 열리고, [🧾 작업도면]으로 그 부품의 A4 그림(PartList 등록)을 작업지시용으로 열어 인쇄할 수 있고, [✔ 가공완료 등록]을 누르면 가공비 = 시간 ÷ 60 × 단가로 자동 계산되어 제조원가와 금형원가에 사내가공비로 잡힙니다. 단가는 기준정보 › 단가관리 › 작업단가에서 공정코드 → 설비코드 → MCH(가공 공통) 순으로 찾아옵니다. 창 아래에 어느 단가를 썼는지 표시되고, 작업단가가 하나도 없으면 기본 30,000원/h로 계산한다는 경고가 뜹니다. 시간을 넣어야 원가에 반영됩니다.
  5. 완료 전 칸은 「미완료」, 지금 할 차례면 「▶ 완료등록」, 끝나면 진한 갈색 「✔ 완료」로 바뀌며 누적 시간·금액이 보입니다. 잘못 넣었으면 그 칸을 다시 우클릭해 [↺ 완료취소]를 누르거나, 목록에서 한 줄씩 ✕ 로 지웁니다.
  6. 앞 공정에 아직 완료 등록이 안 된 사내 칸이 있으면 외주 발주창에 알림이 뜹니다(발주는 그대로 가능).
  7. 부품 행을 우클릭하면 공정 편집이 열립니다. 여기서 공정을 넣고 빼거나 사내를 체크한 뒤 [▣ 가공계획 적용]을 누르면 저장됩니다. 목록에서 여러 부품을 체크해 두고 적용하면 체크한 부품 전부에 같은 공정이 들어갑니다(버튼에 「+체크 N개」 표시). 이미 발주가 진행된 부품은 건너뛰고 알려줍니다.
  8. 편집 창은 제목줄을 잡고 끌어 화면 가장자리 밖으로도 밀어 둘 수 있습니다. 제목줄 한 조각만 남아 있으면 다시 끌어올 수 있습니다.
  9. ✉ 발주서 메일 — 발주를 등록하면 바로 발주서 메일 창이 뜹니다. 받는 사람은 기준정보 › 협력업체관리의 이메일이 자동으로 들어가고, 발주 내역표와 PartList에 등록한 부품 그림(A4)이 함께 갑니다. [✉ 보내기]는 구글 앱스 스크립트 웹앱을 통해 회사 구글 계정으로 바로 발송(발주서 PDF + 부품 그림 첨부, 기록은 mail_log), 함수가 아직 없으면 [📨 메일 앱]으로 메일 프로그램을 열고 [🖨 발주서(A4)] 창을 PDF로 저장해 첨부하면 됩니다. 발주 뒤에도 그 공정(품번) 칸을 우클릭해 열리는 입고·확정·완료 창의 [🧾 발주서]로 그 부품의 발주서(같은 업체·발주일 발주건만)를 언제든 다시 열 수 있습니다.
💡 사내가공 실적은 구매관리 › 가공 › 사내가공 실적등록에서 넣은 것과 같은 자료입니다. 어느 화면에서 넣어도 서로 보입니다.

조립실적등록

사내외가공 발주와 같은 격자 구조입니다. 행 = 선택 제번의 PartList(원재료) 부품 + 「★ 금형 전체」 행, 칸 = 랩핑,조립 한 공정. 칸을 우클릭해 작업자·인원·시간을 넣으면 조립비(분 ÷ 60 × 인원 × 단가)가 design_results(조립)에 쌓여 제조원가·금형원가(내역)에 반영됩니다.

  1. 제번리스트에서 제번을 고르면(진행/완료 라디오, 제번·품번 검색) 오른쪽에 부품이 펼쳐집니다. 제번 줄에 누적 시간·조립비·검사횟수가 보입니다.
  2. 부품의 랩핑,조립 칸을 우클릭(또는 더블클릭) → 작업일·작업자(사용자정보)·인원·시간(분)·단가(작업단가 AS → 조립 ASM 순)·비고를 넣고 [✔ 실적 등록]. 같은 부품에 여러 날 누적되며, 창 아래 목록에서 ✕ 로 한 건씩 지우거나 [↺ 전체 취소]로 모두 지웁니다.
  3. 합형·T/O 처럼 특정 부품에 매지 않는 시간은 맨 위 ★ 금형 전체 행에 넣습니다.
  4. 여러 부품을 체크해 두고 한 칸을 우클릭하면 체크한 부품에 함께 등록됩니다 — 넣은 시간을 부품 수로 나눠 넣거나(기본) 각 부품에 같은 시간으로 넣을 수 있습니다.
  5. 칸 색: 연한 갈색 = 미등록, 진한 갈색 = 실적 있음(누적 h · 원 · 건수). 「최근 작업」 열에 마지막 작업일·작업자.
  6. [▣ 조립 완료] — 제번 조립 완료 처리(완료 목록으로 이동). [검사시트 작성/수정] — 검사횟수 +1, 검사실적등록의 조립검사 대상 생성. [▤ EXCEL] — 실적 전체 내려받기.
  7. 금형원가(내역) 화면의 「랩핑,조립 사내」 칸과 같은 자료를 공유하고, 제조원가 조회 내역표의 「조립·검사비 › 조립」 열에 잡힙니다. 단가는 작업단가의 COM(랩핑,조립) → ASM(조립 공통) 순.

제조원가조회(실시간)

제번별 제조원가를 실시간 집계해 보여줍니다.

  1. 제번·기간 조건을 넣고 [⌕ 검색].
  2. 원재료비·구매비·가공비(사내/사외)·조립비·설계비·경비가 단계별로 집계됩니다. 아래 내역표의 가공비 칸에서 사내(사내가공 실적 = 시간÷60×단가)와 사외(외주가공 입고확정액)를 나눠 볼 수 있고, 둘 다 제조원가에 들어갑니다.
  3. 제번을 클릭했을 때 아래에 「목록의 제조원가와 ○○원 차이」 알림이 뜨면, DB의 제조원가 뷰가 아직 사내가공비를 세지 않는다는 뜻입니다. 관리자에게 sql_v161_cost_view_check.sql 확인을 요청하세요.
  4. 수주가와 비교해 이익률을 확인하고 [▤ EXCEL]로 보고서를 만듭니다.
  5. [₩ 네고조정]: 제번을 하나 체크하고 누르면 가격 협상으로 조정된 금액과 사유를 입력합니다. 실수주가 = 수주가 − 네고조정이고, 이윤과 이익률은 실수주가 기준으로 다시 계산됩니다. 수주등록의 네고조정 칸과 같은 값입니다.
  6. 집계단위를 「관리제번별 합계」로 바꾸면 26IPA001A·B·C 처럼 공정별로 나뉜 제번을 관리제번(26IPA001) 하나로 묶어 수주가·원가·이윤 합계와 공정 수를 보여줍니다. 행을 클릭하면 모든 공정의 원가 내역이 함께 나옵니다. 네고조정·수정·삭제는 제번(공정)별 보기에서 합니다.
💡 집계 기준은 입고확정과 실적등록(사내 작업시간×공정단가)입니다. 숫자가 이상하면 미확정 입고와 미등록 실적부터 확인하세요.

금형원가(내역)

담당자가 쓰던 금형원가 내역 엑셀을 그대로 옮긴 입력 화면입니다. (조회 전용은 아래 「금형원가 내역(부품별)」) 부품이 줄, 가공공정이 칸이고, 공정마다 사내(가공시간 h)와 외주(가공비 원) 두 칸에 바로 적습니다.

  1. 제번을 고르고 [⌕ 조회]. 왼쪽 부품·재료비 칸(입고일·품번·부품명·재질·형태·두께·길이·폭·수·중량·단가·금액)은 PartList와 원재료 입고에서 자동으로 채워집니다. 비어 있으면 그 자리에서 입력하면 됩니다.
  2. 두께·길이·폭·수량을 넣으면 중량이 자동 계산되고(형태에 따라 사각·환봉 식이 달라집니다), 중량 × 단가로 금액이 나옵니다.
  3. 공정 칸에 사내는 시간(2.5 = 2시간 30분), 외주는 금액을 적습니다. 고친 칸은 노랗게 표시되고, [▣ 저장]을 눌러야 DB에 들어갑니다.
  4. 입고일은 5/16 처럼 짧게 적어도 됩니다. 연도는 올해로 채워집니다.
  5. 목록에 없는 부품은 [＋ 부품추가]로 품번을 넣고 나머지를 채웁니다. 저장하면 PartList에도 등록됩니다.
  6. 왼쪽 12칸은 가로로 스크롤해도 고정되어 공정이 많아도 어느 부품인지 놓치지 않습니다. [▤ EXCEL]로 보이는 그대로 내보내고, [⎙ 인쇄]는 A3 가로로 출력합니다.
💡 저장하면 재료비는 원재료 입고확정, 사내는 사내가공 실적, 외주는 외주가공 입고확정으로 들어갑니다. 제조원가조회와 금형원가 내역에 바로 반영되고, 발주 화면에서 따로 입력할 필요가 없습니다.
⚠ 외주 금액은 넣는 즉시 확정으로 기록됩니다. 발주·입고 절차를 거쳐야 하는 건은 외주가공 발주 화면에서 처리하세요. 두 화면에서 같은 공정을 넣어도 중복으로 더해지지 않습니다 — 이 화면은 자기가 만든 값만 고쳐 씁니다.

금형원가 내역(부품별)

제번 하나의 부품(품번)별 재료비와 공정별 가공비를 한 표로 봅니다. 현장에서 쓰던 금형원가 내역 엑셀과 같은 모양입니다.

  1. 제번을 고르면 부품이 줄로, 가공공정이 열로 펼쳐집니다. 열의 이름과 순서는 기준정보 › 가공공정관리를 그대로 따릅니다.
  2. 칸 안의 파란 숫자는 사내 가공시간(h), 갈색 숫자는 외주 확정금액입니다. 괄호 친 회색 숫자는 아직 입고확정되지 않은 발주 금액이라 합계에 들어가지 않습니다.
  3. 재료비는 입고확정된 원재료·구매품 발주에서, 사내 가공비는 사내가공 실적등록에서, 외주 가공비는 외주가공 발주에서 자동으로 모입니다. 따로 입력하지 않습니다.
  4. [◴ 진행현황] 탭은 같은 표에 금액 대신 공정별 완료일을 보여줍니다. 노란 칸이 완료, 파란 칸이 진행 중, 「예정」은 가공계획에만 있고 아직 시작하지 않은 공정입니다.
  5. 관리제번 전체를 체크하면 26IPA001A·B·C 처럼 공정별로 나뉜 제번을 한 표에 모아 봅니다. (회의록 1-1)
  6. 부품줄에는 PartList에서 등록한 재질·형태·규격이 함께 나오고, 그림을 올린 부품은 품번 앞에 작은 사진이 붙습니다.
  7. [▤ EXCEL]은 보고 있는 탭을 그대로 내보내고, [⎙ 인쇄]는 A4 가로로 출력합니다.

업체별 가공비 합계

외주 발주(외주가공·외주설계·원재료·구매품)의 확정금액을 협력업체별로 합산합니다. 월 정산, 업체 거래 규모 파악, 단가 협상 자료로 씁니다. (회의록 6-2)

  1. 구분(기본 외주가공)·기간(입고확정일 기준)·상태(기본 입고확정만)를 정하고 [조회]. [이번 달]·[지난 달]·[올해] 버튼으로 기간을 바로 잡을 수 있습니다.
  2. 집계를 「업체 × 월별」이나 「업체 × 제번별」로 바꾸면 그 단위로 나뉩니다. 비중은 확정금액 합계 대비입니다.
  3. 합계 행을 클릭하면 아래에 발주 내역(제번·품번·공정·금액)이 나옵니다. [EXCEL]로 내보냅니다.
  4. 확정금액 규칙은 제조원가조회와 같습니다: 확정가가 있으면 확정가, 없으면 견적가 × (1 − 네고율).

품질목표 등록

연간 품질 KPI의 목표값을 정하는 화면입니다. 실적은 입력하지 않습니다 — 수주·검사·부적합·시정조치·발주·4M 데이터에서 자동 집계됩니다.

  1. [＋ 신규] → 연도와 KPI 코드를 입력합니다. 코드는 소문자로 넣어도 자동으로 대문자가 됩니다.
  2. 목표키는 「연도|KPI코드」 형식으로 자동 생성됩니다(읽기전용). 예: 2026|KPI01
  3. 지표명·단위(%/건/일/회/점)·목표값을 입력합니다.
  4. 목표방향: 높을수록 좋으면 up(합격률·준수율), 낮을수록 좋으면 down(부적합 건수·소요일).
  5. 주관부서와 정렬순서를 입력합니다. 정렬순서는 달성현황·월별추이 화면의 표시 순서이며, 신규 시 「기존 최대값+10」이 자동으로 채워집니다.
  6. [▣ 저장] — 목록이 연도·정렬순서 순으로 재정렬되고 방금 저장한 행이 선택 표시됩니다.
💡 중간에 지표를 끼워 넣으려면 정렬순서를 25처럼 사이값으로 주면 됩니다. 10단위로 띄워둔 이유입니다.
⚠ 이미 저장된 행을 선택한 상태에서 연도나 KPI코드를 고치면 목표키가 바뀌어 새 행이 추가됩니다. 확인창이 뜨면 의도를 다시 확인하세요. 해가 바뀌면 새 연도의 목표를 반드시 등록해야 실적이 집계됩니다.

품질목표 달성현황

등록된 KPI의 이번 달 실적과 연간 누계(YTD)를 목표와 비교해 보여줍니다. 월간 품질회의 기본 자료입니다.

  1. 열면 자동 조회됩니다. 조회 대상은 올해 목표가 등록된 KPI뿐입니다.
  2. 이번달·YTD·목표대비 컬럼을 확인합니다. 목표대비는 목표방향(up/down)을 반영해 계산됩니다.
  3. 판정 컬럼에서 달성 / 근접 / 미달 / 실적없음을 확인합니다.
  4. 「실적없음」은 아직 원천 데이터가 없다는 뜻입니다. 해당 업무화면에 입력이 필요합니다.
  5. [▤ EXCEL]로 회의자료용 파일을 내려받습니다.

품질목표 월별추이

최근 12개월 KPI 추이를 봅니다. 실적과 함께 분자/분모가 표시되어 산출 근거를 바로 확인할 수 있습니다.

  1. 지표·월 조회조건을 선택하고 [⌕ 검색].
  2. 실적 칸이 비어 있으면 그 달에 원천 데이터가 없는 것입니다.
  3. 분자/분모로 「몇 건 중 몇 건」인지 확인합니다. 예: 준수율 87.5% = 14/16.
  4. [▤ EXCEL]로 추이표를 내려받아 그래프로 가공합니다.
💡 집계 기준월은 완료 시점입니다. 신청일이 아니라 Try-Out 완료일·검사일·부적합 발생일·시정조치 완료일·입고일·고객승인일이 속한 달로 잡힙니다.

심사등록

고객사로부터 받는 심사(수감)와 우리가 협력업체에 실시하는 심사(실시)를 모두 기록합니다.

  1. [＋ 신규] → 심사번호를 입력합니다.
  2. 심사구분을 정확히 고릅니다. 고객이 우리를 심사하면 수감, 우리가 협력업체를 심사하면 실시입니다.
  3. 심사유형(1차사 정기심사/특별심사/내부심사 등), 심사일·종료일을 입력합니다.
  4. 심사기관·심사원·우리측 대응책임자를 입력합니다. 실시 심사라면 피심사 업체를 [⌕]로 선택합니다.
  5. 심사범위·기준서명·점수·만점·등급·결과(합격/조건부합격/불합격)·차기심사일을 입력합니다.
  6. 보고서번호와 상태(계획/진행/완료)를 입력하고 [▣ 저장].
💡 저장 후 지적사항등록에서 이 심사번호를 선택하면 지적사항이 연결됩니다.

지적사항등록

심사에서 나온 지적사항을 항목별로 기록하고 조치를 관리합니다.

  1. [＋ 신규] → 지적번호를 입력하고 심사번호를 선택합니다.
  2. 항목번호·지적분야·등급(Major/Minor/관찰)·요구사항·지적내용·객관적 증거를 입력합니다.
  3. 조치책임자와 조치기한을 지정합니다. 기한은 지적사항 조치현황의 지연 알림 기준입니다.
  4. 조치계획·완료일·검증결과·상태(미조치/조치중/완료/검증완료)를 입력하고 [▣ 저장].
💡 저장하면 시정조치서(CAR)가 자동으로 발행되어 시정조치등록 화면에 나타납니다. 별도로 CAR을 만들 필요가 없습니다.
⚠ 자동 발행은 Major·Minor 등급에서 동작합니다. 여러 건을 엑셀 붙여넣기로 한꺼번에 저장하면 채번이 충돌할 수 있으니 건별로 저장하세요.

심사현황

심사 이력을 지적사항 건수와 함께 조회합니다.

  1. 심사구분·유형·기간·업체 조건을 넣고 [⌕ 검색].
  2. 지적/중부적합/경부적합/미조치/기한초과 건수 컬럼으로 심사별 조치 상태를 한눈에 봅니다.
  3. 알림 컬럼에 기한초과·미조치가 뜬 심사부터 처리합니다.
  4. [▤ EXCEL]로 내려받습니다.
💡 차기심사일이 임박한 심사도 알림에 표시됩니다. 심사 준비 일정 관리에 사용하세요.

지적사항 조치현황

지적사항을 조치 기한 기준으로 관리하는 화면입니다.

  1. 등급·상태·심사번호로 조건을 걸고 [⌕ 검색].
  2. 잔여일 컬럼을 확인합니다. 음수면 이미 기한이 지난 것입니다.
  3. 알림에 기한초과 / 임박이 뜬 건을 우선 처리합니다.
  4. 연결된 CAR 번호로 시정조치 진행 상태를 확인합니다.
💡 조치가 끝나면 지적사항등록에서 완료일·검증결과를 입력하고 상태를 「완료」로 바꿔야 이 목록에서 빠집니다.

고객 요구사항 등록

고객이 보낸 품질·도면·납기 요구사항을 접수하고 사내 문서·협력업체로 전개한 이력을 남깁니다.

  1. [＋ 신규] → 요구번호를 입력하고 접수일·고객사·요구유형·제목·내용을 입력합니다.
  2. 출처문서(고객 공문번호)와 관련 제번·금형타입을 입력합니다.
  3. 검토 결과(수용/부분수용/불가)·검토자·검토일을 입력합니다.
  4. 내부문서번호를 선택해 어느 사내 문서에 반영했는지 연결합니다.
  5. 협력업체 전개가 필요하면 전개여부를 체크하고 대상 업체와 전개일을 입력합니다.
  6. 적용일·상태(접수/검토중/전개중/완료/보류)를 입력하고 [▣ 저장].
⚠ 상태값은 드롭다운에 있는 값만 쓰세요. 임의 문구를 넣으면 현황 화면의 알림이 「진행중」으로 잘못 표시됩니다.

고객 요구사항 현황

접수된 고객 요구사항의 처리 상태와 경과일을 조회합니다.

  1. 고객사·유형·상태·기간으로 조건을 걸고 [⌕ 검색].
  2. 경과일이 큰데 상태가 「접수」인 건이 방치된 건입니다.
  3. 연결된 내부문서명과 현재 개정번호가 함께 표시되므로 반영 여부를 확인할 수 있습니다.
  4. 알림에 미검토 / 전개지연이 뜬 건을 우선 처리합니다.

부적합등록

검사 불합격, 공정 중 발견, 고객 클레임 등 모든 부적합을 등록합니다. 품질 KPI의 핵심 원천 데이터입니다.

  1. [＋ 신규] → 부적합번호·발생일을 입력합니다.
  2. 발생구분을 정확히 고릅니다. 고객클레임으로 분류된 건만 KPI07에 집계됩니다.
  3. 제번·품번·품명·공정·업체를 [⌕]로 선택합니다.
  4. 불량유형·불량수량·로트수량·내용을 입력합니다.
  5. 처리(재작업/선별/특채/폐기/반품)와 보고자를 입력합니다.
  6. 상태(발생/조치중/완료)와 종결일을 입력하고 [▣ 저장].
💡 검사실적등록에서 판정을 「불합격」 또는 「특채」로 저장하면 부적합이 자동으로 생성되어 이 화면에 나타납니다. 중복 등록하지 마세요. 검사 체크시트의 NG 항목명이 불량유형에, 발주라인의 공정코드가 공정에 자동으로 채워집니다.
💡 고객클레임이거나 불량률 10% 이상이면 시정조치(CAR)까지 자동 발행되고 조치기한은 발생일+14일로 잡힙니다. 검사실적등록 화면 하단에 발행된 번호가 표시됩니다.
⚠ 검사 판정을 나중에 「합격」으로 정정하면 자동 발행된 부적합은 자동으로 종결 처리됩니다. 수동으로 등록한 부적합은 영향을 받지 않습니다.
⚠ 발생구분·상태는 드롭다운 값만 사용하세요. 임의 값은 KPI 집계와 알림에서 누락됩니다.

시정조치등록

부적합 또는 심사 지적사항에 대한 원인분석·재발방지 조치를 기록합니다. KPI08(기한준수율)의 원천입니다.

  1. 목록에서 자동 발행된 CAR을 선택하거나, [＋ 신규]로 직접 만듭니다.
  2. 연결된 부적합번호 또는 지적번호를 확인합니다.
  3. 원인분석과 근본원인을 구분해 입력합니다. 현상과 원인을 섞지 마세요.
  4. 조치계획·조치책임자·조치기한을 입력합니다.
  5. 조치가 끝나면 완료일과 검증결과를 입력하고 유효성을 체크합니다.

  4. [▤ EXCEL]로 월간 부적합 집계를 내려받습니다.

4M변경신청

사람·설비·재료·방법(4M) 변경을 신청하고 사내 승인 → 고객 통보 → 고객 승인까지 관리합니다.

  1. [＋ 신규] → 변경번호·신청일을 입력합니다.
  2. 변경유형(Man/Machine/Material/Method)과 구분(영구/일시)을 선택합니다.
  3. 대상 제번·품번·업체를 선택하고 변경 전·변경 후 내용을 각각 입력합니다.
  4. 변경 사유와 영향 검토(초중종물 검사, 공정능력 재평가 등)를 입력합니다.
  5. 신청자·승인자·승인일을 입력합니다.
  6. 고객 통보가 필요하면 고객통보 체크 + 통보일을 입력하고, 승인을 받으면 고객승인번호·고객승인일을 입력합니다.

💡 고객승인일−신청일이 KPI10(4M 고객승인 소요일)로 자동 집계됩니다.
⚠ 고객 승인이 필요한 변경을 통보 없이 적용하면 중대 부적합이 됩니다. 통보 전에는 적용일을 넣지 마세요.

  3. 특별특성 수와 측정기 미지정 수를 확인합니다.
  4. 알림 관리계획 없음 공정을 관리계획서 등록에서 보완합니다.
💡 신규 금형 착수 전 이 화면으로 한 번 훑으면 공정 누락을 미리 잡을 수 있습니다.

자격종류 등록

사내·사외 자격의 종류를 정의합니다. 사원 자격등록의 선택 목록이 여기서 나옵니다.

  1. [＋ 신규] → 자격코드를 직접 입력합니다.
  2. 자격명·자격군(검사/가공/설계/안전 등)·발급구분(사내/국가/민간)을 입력합니다.
  3. 유효기간(개월)을 입력하면 사원 자격등록 시 만료일이 자동 계산됩니다.
  4. 법정자격 여부와 필요 직무를 지정하고 [▣ 저장].

사원 자격등록

사원별 보유 자격과 유효기간을 관리합니다.

  1. [＋ 신규] → 자격번호를 입력하고 사번을 [⌕]로 선택합니다. 성명이 자동 입력됩니다.
  2. 자격코드를 선택합니다. 자격명이 자동 입력됩니다.
  3. 취득일을 입력하면 자격종류의 유효기간에 따라 만료일이 계산됩니다.
  4. 증서번호·발급기관·등급을 입력합니다.
  5. 상태(유효/만료/정지)를 지정하고 [▣ 저장].
💡 검사원 자격이 만료된 사람이 검사 실적을 올리면 심사에서 지적됩니다. 만료 전에 갱신하세요.

자격 유효현황

전 사원의 자격 유효 상태를 기한 기준으로 조회합니다.

  1. 자격군·상태·법정자격 여부로 조건을 걸고 [⌕ 검색].
  2. 잔여일 오름차순으로 확인합니다.
  3. 알림 만료 / 임박 대상자에게 갱신 교육을 배정합니다.
  4. 법정자격 만료 건은 최우선으로 처리합니다.

교육훈련 등록

사내외 교육 실시 이력과 효과를 기록합니다.

  1. [＋ 신규] → 교육번호·교육일을 입력합니다.
  2. 교육명·구분(사내/사외/OJT)·분야를 입력합니다.
  3. 강사·교육기관·시간·참석인원·참석자 명단을 입력합니다.
  4. 교육 내용과 효과성 평가(효과있음/보통/재교육필요)를 입력합니다.
  5. 자격 취득과 연계되면 자격코드를 연결하고 [▣ 저장].
💡 심사 지적에 대한 조치로 실시한 교육은 내용란에 지적번호를 적어두면 근거 추적이 쉽습니다.

사원별 역량현황

사원별 보유 자격 수와 최근 1년 교육 이수 현황을 한 화면에서 봅니다.

  1. 부서·자격군 조건을 넣고 [⌕ 검색].
  2. 보유/유효/만료 자격 수와 보유 자격 목록을 확인합니다.
  3. 최근 1년 교육 횟수·시간으로 교육 이수 부족자를 찾습니다.
  4. 알림 자격만료 / 교육부족 대상자에게 교육을 배정합니다.
💡 연간 교육계획 수립 시 이 화면을 기준으로 대상자를 뽑으세요.

협력업체 평가등록

협력업체를 품질·납기·대응·가격 4개 항목으로 평가합니다. 점수와 등급이 자동 계산됩니다.

  1. [＋ 신규] → 평가번호·업체코드를 [⌕]로 선택합니다. 업체명이 자동 입력됩니다.
  2. 평가일·평가기간(예: 2026-상반기)·평가구분(정기/수시/신규)·공급분야를 입력합니다.
  3. 품질·납기·대응·가격 점수를 각 100점 만점으로 입력합니다.
  4. 입력하면 가중치(품질40 · 납기30 · 대응15 · 가격15)로 총점·등급·조치가 자동 계산됩니다.
  5. 평가자를 입력합니다. 등급이 낮으면 개선요구 기한과 결과를 입력합니다.
  6. [▣ 저장].
💡 부적합현황에서 해당 업체의 부적합 건수를, 발주현황에서 납기 준수 실적을 확인한 뒤 점수를 매기면 객관적입니다.

협력업체 인증서등록

  2. 인증종류(ISO 9001 / IATF 16949 / ISO 14001 등)·인증서번호·인증기관을 입력합니다.
  3. 발행일과 만료일을 입력합니다.
  4. 인증범위를 입력하고 [▣ 저장].
⚠ 인증이 만료된 업체에 계속 발주하면 고객 심사에서 지적됩니다. 만료 전에 갱신본을 받으세요.

협력업체 등급현황

협력업체 평가 결과·인증 보유·부적합 실적을 한 화면에서 종합해 봅니다.

  1. 거래구분·공급분야·등급 조건을 넣고 [⌕ 검색].
  2. 최근 평가의 총점·등급·조치를 확인합니다.
  3. 인증 수 / 만료 인증 수 / 최근 1년 부적합 건수를 함께 확인합니다.
  4. 알림 미평가 / 인증만료 / 부적합 다발 업체를 관리 대상으로 분류합니다.
  5. [▤ EXCEL]로 협력업체 관리 회의 자료를 만듭니다.
💡 신규 발주 전에 이 화면에서 해당 업체 등급을 먼저 확인하는 것을 원칙으로 하세요.

업체관리

  1. 가공공정관리: 공정코드·공정명·그룹(설계/가공/조립)을 등록합니다. 공정단가·실적의 기준 코드입니다.
  2. 가공 기준공정관리: 좌측에서 공정을 골라 [▶]로 순서에 추가, [◀]로 제거해 기준공정 루트를 만들고 [▣ 저장]. 가공계획·공정이력카드가 이 순서를 전개합니다.

  3. 설비·공정·작업자는 […] 조회로 지정하고 [＋ 지시등록]으로 행을 만든 뒤 [▣ 저장].
  4. 취소는 행 선택 → [✖ 지시삭제].

  2. 검사항목: 구분별 측정 항목과 판정 기준(criteria)을 등록. 검사실적등록 화면의 행이 됩니다.

단가관리 (자재/공정 단가변동)

  2. 공정단가변동등록: 공정그룹·공정·협력업체·적용시작일·단가 — 같은 방식입니다. 사내 실적 인건비 계산에 쓰입니다.
  3. 단가 인상 시 기존 행을 고치지 말고 새 적용시작일로 새 행을 추가하면 이력이 남고, 발주일 기준으로 맞는 단가가 자동 적용됩니다.

에러로그

화면을 쓰다가 오류가 나면 자동으로 여기에 기록됩니다. 「저장이 안 돼요」 같은 신고를 받았을 때 원인을 바로 찾는 화면입니다.

  1. 기간·등급(ERROR/WARN)·화면·사용자·검색어로 조건을 걸고 [⌕ 검색].
  2. 행을 클릭하면 아래에 상세(오류 메시지, 발생 위치, 서버 응답 내용, 브라우저 정보)가 펼쳐집니다.
  3. 담당자에게 전달할 때는 [▤ EXCEL]로 내려받아 첨부하면 됩니다.
  4. [⚠ 테스트]는 표본 로그를 한 건 남겨 수집이 정상 동작하는지 확인하는 버튼입니다.
  5. 정리는 [선택삭제] / [전체삭제] / [90일 이전 정리]를 씁니다.
💡 오류가 났을 때 어느 화면에서, 몇 시에 그랬는지만 알려주면 이 화면에서 바로 찾을 수 있습니다.
⚠ 사용자가 직접 조치할 화면은 아닙니다. 오류가 반복되면 관리자에게 알려주세요.

금형코드 매칭

  1. 제번·품명으로 [⌕ 검색]해 상단 제번 리스트에서 대상 제번을 클릭합니다.
  2. 하단 매칭 표에서 공정 순서·공정코드·조수를 입력하고 [▣ 저장]. 같은 행을 다시 저장하면 수정으로 동작합니다.
  3. 잘못 매칭한 행은 선택 → [✖ 삭제].
💡 SET외주제작등록에서 공정이 안 펼쳐지면 이 화면에서 해당 제번의 매칭이 있는지 먼저 확인하세요.

공정카테고리

  1. 코드·이름·표시 순서를 넣고 [저장]. 저장한 목록이 수주등록의 카테고리 선택과 제조원가조회의 카테고리 필터에 나옵니다.
  2. 아무것도 등록하지 않으면 기본 목록(블랭킹·드로잉·트리밍·피어싱·벤딩·포밍·플랜징·캠·복합)이 쓰입니다.

작업단가

조립·사내가공 노무 단가(원/시간)를 관리합니다. 조립실적·사내가공 실적의 금액 계산 기준입니다. (회의록 3-1·3-2)

  1. 코드 ASM=조립 공통 단가, MCH=가공 공통 단가. 설비별로 다르게 하려면 설비코드를 코드로 등록합니다(구분 가공).
  2. 등록이 없으면 30,000원/h 로 계산합니다. 실적 화면에서 그 건만 단가를 고칠 수도 있습니다.

진척률외주설계 전용. 부분 납품 비율(%)이며 100%가 곧 입고확정입니다.

발주 화면의 자재표가 비어 있다해당 제번의 PartList가 등록되지 않았습니다. 설계관리 › PartList 등록에서 먼저 넣으세요.
「단가 미등록 n건」이 뜬다기준정보 › 단가관리에 그 자재·업체의 단가가 없습니다. 적용시작일이 발주일보다 늦어도 같은 메시지가 뜹니다.

품질목표에 「실적없음」이 뜬다그 KPI의 원천 데이터가 아직 없습니다. 달성현황 화면의 안내에 KPI별 입력화면이 적혀 있습니다.

검사 대상 목록에 안 나온다아직 입고 처리가 안 됐습니다. 발주 상태에서는 검사 대상이 되지 않습니다. 검사실적등록 메뉴는 조립관리 › 검사에 있습니다.
자격이 만료됐다고 경고가 뜬다검사원 자격 만료자입니다. 사원 자격등록에서 갱신하거나 다른 검사자를 지정하세요.
저장이 안 되고 「실패」가 뜬다하단 메시지줄에 원인이 나옵니다. 대개 필수값 누락 또는 미등록 코드입니다. 반복되면 기준정보 › 에러로그에서 시각으로 찾아 관리자에게 전달하세요.

필요한 메뉴가 안 보인다조회 권한이 없습니다. 관리자가 기준정보 › 사용자정보의 권한 트리에서 부여합니다.
